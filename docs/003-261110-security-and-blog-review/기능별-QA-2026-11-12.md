- 성과 상세는 `WebPage`·`website` 유형과 공유용 기본 로고를 사용한다. 확인된 수정일은 JSON-LD·사이트맵에 유지하며, 일반 글의 `BlogPosting` 유형은 유지한다. 실제 검색 결과·외부 공유 서비스 반영은 미검증이다. 성과 제목·설명에 `&`가 들어간 합성 자료에서 JSON-LD 문자 참조가 그대로 남는 조건부 한계는 [추가 사례조사](추가-사례조사-2026-11-13.md)에 기록했다.
- 성과 JSON-LD의 제목과 설명을 브라우저가 읽는 공유 메타데이터와 직접 비교하는 검사를 추가했다. 격리 자료에서 오류를 감지하는지 확인했지만 생성 결과를 수동으로 수정한 시험이므로 문자 참조 결함을 해결했다는 근거는 아니다. 일반 문자, 숫자 문자 참조 및 중첩 참조를 모두 정확히 처리할 안전한 수정이 남아 있다.
- 당시 로컬 글 19개 중 기업재난관리사 후기의 본문 제목 `<자격증> … & 정보글`은 공유·브라우저 제목에서 `<자격증>`이 빠지고 JSON-LD의 `&`도 문자 참조로 남았다. 생성된 37개 문서에서 공유 제목과 JSON-LD 제목을 비교한 결과 불일치가 확인된 것은 이 한 문서였다. 이후 위의 제목 SEO 보완에서 해당 글을 수정했다. HTML 공유값을 JSON-LD에 복사하는 격리 후처리 후보는 공유값 자체가 잘못된 경우 원문을 복원하지 못해 완전한 해결책이 아니었다.
- 성과 SEO 지원 설정 검사가 격리 시험에서도 실제 시험용 설정과 성과 원본을 읽도록 고쳤다. 격리 사본에만 지원하지 않는 사이트·성과 설정을 추가해 검사 실패를 확인했다.
- 성과 SEO 검사의 Markdown 원문 비교 오류를 고치고, 실제 변환 설정으로 기대값을 계산하도록 보강했다. 생성된 Markdown 자료와 두 메타데이터에 동시에 잘못된 문자 참조를 넣은 사례를 확인했다. 변환기 부재 시 단순 평문만 제한적으로 검사하고 경고하며, 실제 SEO 문자 참조 생성 결함은 남아 있다.
- SEO 검사에서 NBSP와 일반 공백, 분해형 문자와 정규형, 스마트 따옴표를 임의로 같은 값으로 취급하지 않게 했다. 정상 입력과 동시 변조 사례, 페이지·사이트 언어 설정의 우선순위를 격리 빌드로 확인했다. 현재 사이트 제목의 스마트 따옴표는 Jekyll 변환기가 필요하므로 gem이 없는 시스템 Ruby만으로 단독 SEO 검사를 실행하면 명시적으로 실패한다.
- 코드 복사가 지연된 뒤 재시도해도 지연 안내를 유지한다. 원래 요청의 늦은 성공·실패와 다른 버튼의 대기 상태는 격리 테스트로 확인했다. 브라우저 요청이 끝나지 않으면 자동 복사도 계속 대기하며, 실제 브라우저에서 무기한 대기가 발생하는지는 확인하지 못했다.
- 성과 주소의 기저 경로 중복을 방지하고 비슷한 이름의 다른 경로를 구분했다. `/blog`의 내부 프로젝트 링크 이동과 이미지 로드는 Chrome에서 확인했다. 목적지와 이미지는 임시 시험 자료다.
- 사이드바 검색, 모바일 메뉴, 도구 탭의 방향키·Escape·Tab 처리에서 수정 키나 입력기 조합 및 이미 처리된 이벤트를 존중하도록 개선했다. 일반 탐색과 조합 이벤트는 격리 DOM 테스트로 확인했으며, Chrome 모바일 크기에서는 일반 Escape로 검색 결과와 메뉴가 차례대로 닫히는 흐름을 확인했다. 수정 키 이벤트의 실제 운영체제별 전달은 확인하지 않았다.
- 성과 목록·상세에서 텍스트와 URL 속성을 이스케이프하고 내부 루트 경로에 사이트 기저 경로를 적용한다. 현재 자료에 없는 선택 필드를 합성 자료로 넣어 기본·`/blog`·`/blog/` 빌드에서 특수문자와 내부·외부 주소를 확인했다. 명시적 스킴은 HTTP(S)만 허용하며 제어문자·역슬래시·앞뒤 공백 등은 거부한다. 발행 전 명시값 및 실제 상속값 검사를 제공하지만 URL 호스트나 대상의 존재는 확인하지 않는다.
- 성과 URL 합성 사례에서 Liquid 출력과 Ruby 검증의 허용·거부 결과를 대조했다. GitHub Pages 구성의 실제 문서 데이터로 기본값 경로·우선순위·`false`/`null` 상속도 별도 검사한다. 두 구현의 동기화와 유한한 시험 사례의 한계는 남는다.
- 성과 기본값 검사에서 컬렉션이 없거나 검사 문서가 0건이면 성공으로 보고하지 않는다. 단독 front matter 검사는 사이트 내부 파일을 가리키는 성과 심볼릭 링크도 살피며, 보이는 외부·끊김·순환·디렉터리 링크는 보수적으로 거부한다. 기본적으로 숨김 항목은 제외하고, 명시적 include로 노출된 문서는 별도 Jekyll 유효값 검사에서 확인한다.
- 공백과 한글이 포함된 격리 복사본에서 로컬 `.bundle`, 루트 `Gemfile.lock`, 기존 `_site`와 `build`를 제외한 뒤 `npm run verify` 전체가 통과했다. 미추적 소스와 후보 잠금 파일은 포함했고, 기존 `node_modules`와 격리 Ruby gem은 재사용했다. 따라서 새 Git 체크아웃에서의 설치나 Linux·Actions 검증을 뜻하지 않는다.
- 표준 모형 글의 404 참고문헌 주소를 [PDG 2024 공식 목록](https://pdg.lbl.gov/2024/reviews/standard_model_and_related.html)이 가리키는 힉스 보손 자료로 수정했다. PDF 본문 전체는 확인하지 않았다.
- 위 개수는 특정 명령의 테스트·검사 대상 수이며 분기 커버리지나 실제 사용자 검증률이 아니다.
- 속력의 정의와 절대온도 기준 확인: [OpenStax 물리학](https://openstax.org/books/physics/pages/2-section-summary), [NIST Kelvin](https://www.nist.gov/si-redefinition/kelvin-introduction).

## 추가 기능 검수

- `/not-found/posts`처럼 주소가 `/posts`로 끝나는 404 화면에서도 사이드바 검색 폼이 있으면 즉시 검색을 초기화한다. 원래 주소를 유지한 HTTP 404 응답을 반환하는 로컬 서버와 실제 브라우저에서 검색 결과와 결과 페이지 이동을 확인했다. 공개 GitHub Pages의 해당 주소에서는 확인하지 않았다.
- MathJax의 주 스크립트뿐 아니라 동적 글꼴 구성요소 로드나 초기 조판 Promise가 실패할 때도 수식 안내를 표시한다. Chrome에서 동적 글꼴 파일만 차단했을 때 안내가 표시되고, 정상 연결에서는 수식이 표시되면서 안내가 숨겨지는 것을 확인했다. 모든 초기화 예외나 개별 수식 오류를 감지한다고 보장하지 않는다. [MathJax 초기화 안내](https://docs.mathjax.org/en/v4.1/web/actions.html).
- 성과 화면의 제목과 날짜·안내를 한국어로 맞추고, 기존 영어 경력 내용은 원문을 보존하며 콘텐츠 언어를 표시했다. 루트 생성물에서 영어와 한국어의 언어 상속을 검사했으며 실제 스크린리더 낭독은 미검증이다. [W3C 언어 표시 안내](https://www.w3.org/WAI/WCAG22/Understanding/language-of-parts.html).
- 수식 로더가 실패하면 글 본문 앞에 오류와 새로고침 안내를 표시하고, 자바스크립트가 꺼진 경우에는 별도 안내를 제공한다. 로컬 서버가 수식 스크립트에 HTTP 503을 반환하도록 한 실제 브라우저에서 안내를 확인했고, 정상 수식 글에서는 안내가 숨겨진 채 수식이 표시됐다. 자바스크립트 비활성 상태는 생성 HTML로만 확인했으며, 로더 성공 후의 내부 렌더링 오류는 감지 범위가 아니다.
- 이슈 번호가 지정된 두 글의 댓글 대체 링크를 해당 GitHub 이슈로 연결했다. 번호가 없는 글은 전체 목록을 유지하고, 별도 Liquid 테스트에서 잘못된 숫자·문자열을 기본 경로로 처리하는지 확인했다. 댓글 작성은 시험하지 않았다.
- 글 목록 검색의 경로 비교에서 인코딩된 구분자, 이중 인코딩, 서로 다른 한글 정규형을 구분하고 잘못된 이스케이프는 색인에서 제외한다. 같은 원인의 잔류 후보를 조사했을 때 사이드바 비교는 이미 구분했고, 글 목록의 글 병합과 도구·시리즈 분류는 수정했다. 생성물 검사 코드의 경로 디코딩은 파일 접근·검사에 사용되며 실제 사이트 링크 병합 경로와는 다르다. 현재 글 주소에 충돌이 있었다는 뜻은 아니다.
- 두 검색 화면이 같은 빌드 버전의 검색 색인 주소를 요청하도록 변경했다. 글 목록 재시도는 브라우저 캐시를 우회해 다시 요청한다. 503 오류를 한 번 반환하는 로컬 서버와 실제 브라우저에서 제한 검색 안내 후 재시도로 본문 검색 결과가 복구됐고, 서버에서 버전 쿼리와 재시도의 `no-cache` 요청 헤더를 확인했다. CDN의 쿼리별 캐시 처리와 배포 전후 모든 버전의 일치는 검증하지 못했다.
- 수식이 있는 글 6편을 로컬 Chrome에서 열어 수식 130개가 렌더링되고 오류 요소가 없음을 확인했다. CDN 장애와 실제 스크린리더 낭독은 미검증이다.
- 수학과 무한 글에서 무한 호텔의 직관에 어긋나는 성질과 러셀의 역설에서 생기는 무제한적 집합 구성의 모순을 구별했다. [Stanford 수학 기초 자료](https://math.stanford.edu/~feferman/papers/foundations.pdf)를 대조했으며 해당 구간을 독립 재검토했다.
- 검색 색인의 글이나 페이지가 통째로 누락되거나 중복된 경우 기대 경로와 비교해 불완전 상태로 안내한다. 이중 인코딩과 서로 다른 유니코드 정규형의 경로가 합쳐지지 않는지도 격리 테스트와 독립 검토로 확인했다. 로컬 브라우저에서는 정상 색인 검색과 글 한 건을 제거한 색인의 오류 안내·글 목록 대체 검색을 확인했다. `/blog` 경로는 생성물·격리 테스트로 확인했다.
- 수학 증명 글의 조건명제 귀류법, 사영 평면의 양화사, 복소 로그 주값 설명과 0 나눗셈 예제를 교정했다. [MIT 증명 자료](https://ocw.mit.edu/courses/6-1200j-mathematics-for-computer-science-spring-2024/mit6_1200j_s24_lec02.pdf)와 [NIST 복소 로그 정의](https://dlmf.nist.gov/4.2)를 참고했으며 해당 구간을 독립 재검토했다.
- 표준 모형 글의 초기 우주 연표에서 플라스마와 원자핵 형성 시기를 바로잡고, 첫 별의 미확정 상태와 초기 은하의 관측을 구분했다. [CERN 초기 우주 설명](https://home.cern/science/physics/early-universe/)과 [NASA 초기 은하 관측](https://science.nasa.gov/missions/webb/nasa-webb-pushes-boundaries-of-observable-universe-closer-to-big-bang/)을 대조했고 해당 구간을 독립 재검토했다.
- 시리즈 카드의 흐린 포커스 윤곽이 진한 공통 윤곽을 덮는 문제를 수정했다. 로컬 브라우저에서 키보드로 카드에 이동해 진한 3px 윤곽이 계산되는 것을 확인했다. [W3C 포커스 표시 설명](https://www.w3.org/WAI/WCAG22/Understanding/focus-visible.html)에 따라 표시 여부를 점검한 것이며 전체 WCAG 적합성 평가는 아니다.
- 검색 기록과 계산기 탭 전환 후 뒤로 갈 때 선택된 탭과 키보드 포커스가 어긋나는 문제를 수정했다. 로컬 브라우저에서 단위 변환 → 검색 → 물리 공식 → 뒤로 가기 시 단위 변환이 선택되고 포커스도 돌아온 것을 확인했다. 탭 외부 포커스 유지와 동일 탭 복원은 격리 테스트로 확인했다.
- 수학 글 네 편과 과학 글 두 편에서 개행만으로 구분해 붙어 보이던 기호 설명·예시·특징을 문맥에 맞게 목록이나 문단으로 나눴다. 수정 전 실패하고 수정 후 통과하는 생성 HTML 테스트를 추가했다. 글 내용의 학술적 정확성 전체를 검증한 것은 아니다.
- CSS 글과 위의 수학·과학 글은 실제 본문 표시를 고친 날짜로 갱신일을 바꿨다. 생성된 CSS 글의 표시 날짜·구조화 데이터와 피드에 포함된 수학 글의 갱신일을 검사했다. 자동으로 모든 글의 날짜를 바꾸지는 않았다.
- 표준 모형 글의 은하 후퇴 설명에서 가까운 은하의 예외를 밝히고, 가속 팽창과 빅 립을 구별했다. 서로 다른 질량의 문제와 전기약 계층 문제도 구분하고 정확한 정의 없이 단정한 쿼크 질량비를 제거했다. [NASA 은하 설명](https://science.nasa.gov/missions/hubble/hubble-sees-sculpted-galaxy/), [NASA 우주 미래 시나리오](https://science.nasa.gov/asset/hubble/possible-fates-of-the-universe/), [CERN 힉스 질량 설명](https://home.cern/science/physics/supersymmetry/), [PDG 쿼크 질량표](https://pdg.lbl.gov/2025/tables/rpp2025-sum-quarks.pdf)를 대조했다. 확인 범위는 이 주장들에 한정한다.
- 글 색인의 본문이 비어 있으면 사이드바도 인덱스를 불완전하게 취급한다. 본문을 빈 값으로 바꿔 응답하는 로컬 서버와 실제 브라우저에서 사이드바의 오류 안내, 글 목록 이동, 본문 누락·재시도 안내를 확인했다. 본문이 없는 일반 페이지는 허용하며, 의도적으로 본문 없는 글을 게시한다면 두 검색 화면의 정책을 함께 재검토해야 한다.
- 운영 빌드를 일부 로컬 주소로 미리 볼 때 분석 태그가 실행될 수 있던 조건을 수정했다. `0.0.0.0`과 IPv6 루프백을 포함한 로컬 주소는 태그 초기화에서 제외하고, 공개 사이트의 기존 분석 설정 호출은 유지한다. 초기화 스크립트를 격리 실행해 주소별 동작을 검사했으며 GA 계정 설정이나 실제 수집 여부는 변경·검증하지 않았다.
- 옛 글 이동 후 뒤로 가기 반복 가능성은 Chrome에서 소개 → 옛 주소 → 현재 글 → 뒤로 가기 순서로 확인했으나 재현되지 않았다. 다른 브라우저 전체를 확인한 것은 아니다.
- HTML 코드 예제의 검색 인덱스에 남은 문자 참조 때문에 `<h1>` 같은 검색어가 일치하지 않는 문제를 수정했다. 두 검색 화면에서 로컬 브라우저로 `<h1>` 검색 결과를 확인하고, 오류 후 제한 검색과 재시도는 격리 테스트로 확인했다.
- CSS 글에서 코드 펜스가 문서 내용으로 표시되고 HTML 예제가 실제 요소로 해석되던 문제를 수정했다. 생성 HTML 회귀 검사와 로컬 브라우저에서 HTML·CSS 예제 표시를 확인했다.
- 옛 글 주소에서 이동할 때 로컬 미리보기가 공개 도메인으로 이동하던 문제를 수정했다. 루트·`/blog` 경로 및 외부 주소 구분은 통합 검사로, 로컬 옛 주소에서 현재 글로의 이동은 브라우저로 확인했다.
- 성과 목록에서 각 상세 페이지로 이동할 수 있도록 연결하고, 상세 페이지의 이전·다음·관련 성과 링크에 사이트 기저 경로를 반영했다. 루트와 `/blog` 생성물의 목록·이전·다음 링크를 검사했고 루트 로컬 브라우저에서 목록에서 상세로 이동했다.
- 사이드바에서 검색어를 입력한 뒤 검색을 제출할 때 같은 주소가 이력에 중복되는 문제를 수정했다. 로컬 브라우저에서 검색 전 상태로 뒤로 간 뒤 앞으로 가면 검색어와 결과가 복원되는 것을 확인했다. 검색어를 지운 뒤 빈 검색을 제출하는 경로는 격리 DOM 테스트로 확인했다.
- 사이드바 검색 결과에 키보드 포커스를 둔 채 뒤로 가면 결과가 교체되며 포커스가 사라지는 문제를 수정했다. 로컬 브라우저에서 `수학` → `물리` 검색 후 결과에 포커스를 두고 뒤로 이동했을 때 `수학` 결과와 검색 입력란의 포커스가 복원되는 것을 확인했다. 검색 → 시리즈 → 뒤로 가기에서도 검색어와 결과가 복원됐다. 실제 기기와 스크린리더 검증은 아니다.
- 가속도 안내의 음의 가속도와 감속을 혼동한 설명을 수정했다. 직선 운동에서 기준 방향과 속력 감소를 구분하고, -10 m/s에서 -5 m/s로 변하는 예를 추가했다. [OpenStax 가속도 설명](https://openstax.org/books/college-physics-ap-courses-2e/pages/2-4-acceleration).
- 사이드바 검색의 결과 주소도 정식 사이트의 출처와 기저 경로를 검증해 현재 호스트의 안전한 경로로 연다. 로컬 브라우저에서 `가속도` 검색 후 결과를 선택했을 때 공개 사이트로 이탈하지 않고 로컬 안내 페이지가 열리는 것을 확인했다.
- 두 검색 화면 모두 생성 인덱스의 검색 필수 필드 누락을 감지한다. 사이드바는 글 목록으로 대체 검색하고 글 목록은 사용 가능한 결과와 재시도를 제공하며 불완전 상태를 표시한다. 손상 데이터의 모든 조합을 시험한 것은 아니다.
- 같은 단위 변환은 입력과 절대영도 검사를 거친 뒤 입력 문자열을 보존한다. `4e-324 m → m`과 다른 단위 변환, 범위 밖 입력, 절대영도 미만 입력을 격리 DOM에서 확인했다.
- 일반 계산기의 12자리 일괄 반올림을 없애 유효한 십진수 자릿수와 연속 계산을 보존했다. 순환소수는 17자리로 반올림하고 이후 계산에도 근삿값 안내를 유지한다. 입력·결과 범위를 벗어난 경우 오류와 복구 방법을 표시한다.
- 물리 공식과 단위 변환도 입력 십진수와 변환 계수를 기준으로 계산하고 표시 시 17자리를 넘겨 반올림한 결과에는 근삿값임을 알린다. 온도 절대영도 경계, 77개 길이·질량·시간 변환쌍, 온도 9개 방향을 격리 DOM에서 확인했다. 계산 결과는 측정 오차나 입력의 유효숫자를 추정하지 않는다.
- 검색 인덱스의 잘못된 항목을 정상 데이터로 취급해 오류를 반복하던 문제를 수정했다. 사이드바에서는 글 목록의 제한 검색으로 이동하고, 글 목록에서는 유효한 결과를 유지하면서 누락 가능성과 재시도를 안내한다. 기대되는 도구·시리즈 페이지가 통째로 누락된 경우도 표시한다.
- 검색 결과 주소의 인코딩을 보존하고 글 목록에서 잘못된 프로토콜·외부 호스트·기저 경로 밖의 주소를 제외한다. 루트·하위 경로 및 미리보기 호스트는 격리 테스트와 생성물 검사에서 확인했다.
- 390px 로컬 브라우저에서 검색 인덱스에 503 오류를 반환하고 모바일 메뉴에서 검색했을 때, 글 목록에 검색어와 제한 검색 결과가 표시되고 메뉴는 닫힌 상태로 유지되는 것을 확인했다. 같은 화면 크기에서 긴 계산 결과가 넘치던 문제를 수정하고 줄바꿈과 순환소수 안내를 확인했다. 실제 기기와 스크린리더 검증은 아니다.
- 실제 로컬 브라우저에서 `1234567890123 kg × 1 m/s²`는 `1234567890123 N`, `1234567890123 m`는 `1234567890123000 mm`로 표시됐다. 다만 브라우저 접근성 상태의 숫자 입력 `Value`가 실제 입력 문자열과 다르게 표시되고 `Details`에는 원래 값이 표시됐다. 스크린리더가 어느 값을 읽는지는 확인하지 못했다.
- 별도 시험 페이지에서 기본 숫자 입력, `aria-valuetext`를 동기화한 숫자 입력, 문자열 입력을 비교했다. 이 시험의 접근성 스냅샷에서는 앞의 두 숫자 입력 모두 `Value`가 원문과 달랐고, 문자열 입력의 `Value`는 원문과 같았다. 실제 스크린리더 낭독과 다른 브라우저에서의 결과는 확인하지 못했으므로 입력 방식 변경이나 속성 추가를 해결책으로 확정하지 않았다.

### 숫자 정밀도 잔류 회귀 점검

원인은 결과를 공통으로 12자리로 줄인 문자열을 표시와 후속 계산에 사용한 것이다. `toPrecision`, 계산 결과 서식, 물리 공식과 단위 변환 호출처를 함께 대조했다.

| 경로 | 판단과 근거 | 처리 |
| --- | --- | --- |
| 일반 계산 | 큰 수와 작은 소수의 유효 자릿수가 사라지고 연속 계산에도 반영됨 | 십진 연산 및 근사 안내로 수정, 회귀 테스트 추가 |
| 물리 공식 | 같은 서식으로 입력 자릿수가 사라짐 | 십진 계산과 표시 반올림 안내로 수정, 5개 공식 및 경계 검사 |
| 단위 변환 | 같은 서식으로 변환 결과의 유효 자릿수가 사라짐 | 십진 변환과 표시 반올림 안내로 수정, 단위쌍·온도 경계 검사 |
| 같은 단위 변환 | 산술 결과를 새로 반올림할 필요가 없음 | 입력값 그대로 표시하는 기존 동작 유지 |

독립 유리수 공식으로 온도 변환 18,000개와 길이·질량·시간 변환 539개를 추가 대조했다. 이 시험은 측정 오차, 모든 입력, 실제 보조기술 동작을 보증하지 않는다.

### 이전 기능별 점검

- 검색 인덱스의 지연 완료 이후 닫은 결과가 다시 열리는 문제, 빈 배열 또는 잘못된 인덱스에서 오류 안내가 없는 문제, IME 조합 중 방향키·Escape 처리 문제를 수정했다. 지연 응답과 오류, 재포커스는 격리 DOM 테스트로 확인했다.
- 모바일 메뉴가 열려 있을 때 포커스가 가려진 건너뛰기 링크로 이동하던 문제를 수정했다. 390px 로컬 브라우저에서 Tab·Shift+Tab 순환과 Escape 후 포커스 복귀를 확인했다. 실제 기기 및 보조기술 검증과는 구분한다.
- 극단적인 숫자 입력의 언더플로 안내와 에너지 계산의 중간 곱셈, 화씨에서 섭씨로 변환할 때의 정밀도를 보완했다. 관련 테스트는 격리 DOM에서 실행했다.
- 과거 주소로 만들어진 댓글 이슈 [#1](https://github.com/allenkang92/allenkang92.github.io/issues/1), [#3](https://github.com/allenkang92/allenkang92.github.io/issues/3)을 각 글에 다시 연결하도록 생성 설정을 수정했다. [Utterances 공식 속성 처리 코드](https://raw.githubusercontent.com/utterance/utterances/master/src/page-attributes.ts)에 따라 두 글에는 issue-number만 출력하고 나머지 글에는 기존 pathname을 사용한다. 로컬 브라우저에서 과학 글 댓글 4개와 수학 글 댓글 1개의 표시를 확인했다. 댓글 게시 동작과 닫힌 이슈 전체는 확인하지 못했다.
- 메뉴가 열린 상태에서 건너뛰기 링크도 배경과 함께 접근성 트리에서 제외하고, 저장된 열린 메뉴 복원 시 포커스를 메뉴로 옮긴다. 390px 브라우저 접근성 트리에서 메뉴 열기·새로고침·닫기를 확인했다. 실제 스크린리더는 미검증이다.
- 수학철학 서론의 확인된 과거 `.html` 주소에 현재 글로 이동하는 페이지를 추가했다. 과학·수학 서론의 옛 주소 두 개는 생성 HTML과 실제 대상 글을 검사했다.
- 화씨에서 켈빈으로 변환할 때 절대영도 바로 위의 입력이 0으로 표시되는 상쇄 문제를 수정하고 격리 DOM 테스트를 추가했다. 현재는 십진수 연산을 사용하며 입력·결과 범위와 표시 반올림 제약이 남는다.
- 글 목록과 사이드바 검색 인덱스 요청이 응답하지 않을 때 각각 12초와 10초 후 오류와 검색 폴백을 안내한다. 늦은 응답과 재시도 중 포커스 이동을 격리 DOM에서 검사했다. 실제 네트워크 지연 환경은 미검증이다.
- JavaScript 미실행 모바일에서 동작하지 않는 메뉴 버튼을 숨기고, 모바일에서 데스크톱 폭으로 바꿀 때 해당 버튼의 포커스를 보이는 메뉴로 옮긴다. 후자는 로컬 브라우저에서 확인했고, JavaScript 미실행 상태는 격리 DOM에서 검사했다.
- PDF 미리보기 밖에 직접 열기 링크를 추가했다. 루트와 `/blog` 경로에서 생성 결과를 검사했다.
- 루트와 `/blog` 격리 빌드에서 manifest·robots 경로, Atom 언어, Open Graph locale과 테스트용 `build/` 미포함을 확인했다. 실제 웹 앱 설치와 검색엔진 색인 동작은 미검증이다. 서브경로의 robots 설정은 도메인 루트 호스팅 구성에도 영향을 받는다.
- 검색 인덱스 요청에 HTTP 503을 반환하는 로컬 테스트 서버와 실제 브라우저로, 사이드바 오류 안내 후 Enter로 글 목록에 이동해 부분 검색 결과와 재시도 버튼이 표시되는 흐름을 확인했다. 10초·12초 타임아웃 자체는 격리 DOM 테스트에서 확인했다.
- 도구의 history 복원 시 숨겨지는 패널이나 제거되는 물리 입력에 있던 포커스를 복구하고, 0으로 나누기 오류 문구를 실제 복구 동작에 맞췄다. 관련 검사는 격리 DOM 테스트이며 실제 브라우저의 history·스크린리더 조작은 미검증이다.
- 이전 저장소 상태를 UTC 기준으로 실제 빌드해 확인한 옛 글 주소 18개를 현재 글에 연결했다. 기존에 보존하던 두 주소를 포함해 총 20개 이동 경로를 루트 및 `/blog` 하위 경로에서 검사했다. 당시 외부 배포 성공 여부와 실제 이용 여부는 확인하지 못했다.
- 검색어를 바꾼 직후 이전 결과를 선택할 수 없게 하고, 앞뒤 공백만 바뀌었을 때는 결과를 불필요하게 다시 생성하지 않도록 수정했다. 관련 동작은 격리 테스트로 확인했다.
- 데스크톱 메뉴에 포커스가 있는 상태에서 접힌 모바일 메뉴로 전환할 때 포커스를 메뉴 버튼으로 옮긴다. 390픽셀 로컬 브라우저에서 확인했으며, 실제 기기와 스크린리더는 미검증이다.
- 옛 주소의 이동 안내를 한국어로 바꾸고 자바스크립트가 실행될 때 문단 위치를 유지한다. 로컬 옛 주소에서 실제 브라우저로 이동해 문단 주소가 유지되는 것을 확인했다. 자바스크립트가 꺼진 경우에는 글로 이동하지만 문단 위치는 유지되지 않는다.
- 자바스크립트가 꺼져 있거나 도구 스크립트를 불러오지 못하면 계산기 버튼을 숨기고 사용 안내와 계산 안내 링크를 유지한다. 도구 스크립트에 503 오류를 반환하는 로컬 서버와 실제 브라우저로 실패 안내를, 정상 서버에서는 1+2=3 계산을 확인했다. 브라우저 자체의 자바스크립트 차단 상태와 실제 기기는 미검증이다.
- 이미 표시된 검색어를 다시 제출해도 결과를 재생성하지 않아 검색 결과의 포커스가 사라지지 않도록 수정했다. 격리 테스트로 확인했다.
- 옛 문서와 현재 문서의 제목을 대조해 바뀐 문단 식별자 3개를 현재 제목에 연결했다. 세 연결 모두 생성물에서 검사했고, 한 사례는 로컬 브라우저에서 옛 주소부터 현재 문단까지 이동해 확인했다.
- 글 목록의 인덱스가 늦게 도착하면서 포커스된 결과가 사라지면 보이는 결과로 포커스를 복구한다. 지연 응답과 임시 시험 자료를 사용한 로컬 브라우저에서 해당 흐름을 확인했다. 사용자가 그 사이 다른 곳을 조작하면 복구하지 않는 경로는 격리 테스트에서 확인했다. 실제 운영망과 스크린리더는 미검증이다.
- 현재 페이지 번호를 다시 선택한 뒤 검색할 때 입력란의 포커스가 이전에 예약된 결과로 옮겨지는 문제를 수정했다. 검색어를 입력 중일 때 현재 페이지 번호를 선택하는 경우도 격리 테스트로 확인했다.
- 동적 글 목록을 사용할 수 없을 때 정적 목록에 검색어가 적용되지 않는다는 안내를 명확하게 표시한다.
- 실제 로컬 브라우저에서 두 번째 목록으로 이동한 후 현재 페이지 재선택·검색·뒤로 가기·앞으로 가기를 확인했다. 실제 운영체제의 한글 조합 입력은 별도로 확인하지 못했다.
- 생성된 글 19개의 목차 제목과 링크, 식별자 충돌 및 빈 제목을 반복 검사하는 테스트를 통합 실행에 추가했다.
- 공개 사이트를 Chrome의 390×844 CSS 픽셀 화면에서 확인했다. 모바일 메뉴와 시리즈 탐색, 글의 목차 이동, 검색 결과의 페이지 이동과 뒤로 가기, 음수 온도 변환은 확인한 사례에서 정상 동작했다. 실제 모바일 기기와 보조기술은 검증하지 않았다.
- SEO 2.8 호환 가드는 출력하지 않는 작성자 소셜 값, 페이지 이동 경로와 정규 주소 때문에 빌드를 중단하지 않도록 보정했다. 출력되는 위험 값 차단과 정상 값 허용은 자동 테스트 및 SEO 2.8 템플릿을 이용한 혼합 환경에서 확인했다. GitHub Pages 232 전체 환경 재현은 아니다.

## 남은 확인

- Chrome은 텍스트 fragment 지시자를 스크립트에 노출되는 URL에서 제거한다. 자동 복원 제거 후에는 격리 Chrome에서 저장 위치가 있어도 대상 문구가 강조되고 해당 위치로 이동했다. 공개 배포본과 다른 브라우저는 확인하지 않았다. [WICG 텍스트 fragment 초안](https://github.com/WICG/scroll-to-text-fragment#fragment-directive).
- 이전 위치로 이동한 화면에 포커스할 수 있는 본문 요소가 없을 때의 임시 표식은 위의 합성 Chrome 시험에서 표시와 다음 Tab 순서를 확인했다. 실제 공개 자료에서 이 예외 경로가 발생하는지와 실제 스크린리더 동작은 확인하지 못했다. 별도의 320×120·320×40 CSS 픽셀 시험에서는 임시 표식이 나타나지 않았고 본문 또는 글 메타데이터에서 다음 글 링크로 Tab 이동했다.
- 글 목록의 이력 위치는 현재 탭 세션에 이력별로 최대 50개를 저장하며 식별이 불가능한 경우 복원 안내를 숨긴다. Chrome에서 동일 주소의 서로 다른 이력과 BFCache 적용·미적용 조건을 일부 확인했다. 결과 높이가 크게 변하거나 Safari 등 다른 브라우저를 사용하는 경우는 확인하지 못했다.
- 생성물 검사기의 출처 비교는 일반적인 HTTP(S) 주소와 기본 포트를 처리하지만, IDN·비표준 IPv4 등 모든 브라우저 URL 표기와의 동등성은 검증하지 않았다. 모호한 일부 표기는 조용히 건너뛰지 않고 검증 오류로 처리한다.
- 합성 시험에서 제목 ID `가`와 `%EA%B0%80`이 함께 있으면 두 목차 링크가 같은 직렬화된 fragment로 연결돼 다른 제목을 가리켰다. 현재 게시 글에서 발생한 사례는 확인되지 않았다. 기존 ID를 유지하면서 작성자가 제목 안의 정적 별칭을 명시할 수 있도록 보완했으며 사용법은 README에 기록했다. 이 방법은 별칭을 지정한 글에 한정되며 자동으로 모든 충돌을 고치지는 않는다. 생성물 테스트는 외부 CSS나 모든 반응형 화면에서 별칭의 가시성을 보장하지 않는다.
- 사이드바 검색 제목의 Chrome 접근성 이름에 강조 경계 공백이 생기는 문제는 텍스트를 하나로 묶어 수정했다. 실제 스크린리더의 언어·강조 낭독은 확인하지 못했다.
- 격리 빌드 검증은 실행마다 시스템 임시 폴더에 시험 자료와 산출물을 남긴다. 2026-11-13 점검 시 이름에 `fixture`가 포함된 임시 폴더 139개가 약 1.8GiB였으며, 이름만으로 모든 폴더의 소유자를 확인할 수는 없었다. 디스크 여유 공간은 시간에 따라 변동하므로 검증 전 확인이 필요하다.
- 성과 제목에 Markdown을 쓰면 본문에는 원문이 보이고 SEO에는 변환된 평문이 출력된다. 화면의 Markdown 입력 계약은 정리가 필요하다. SEO 검사는 Jekyll과 Pages의 변환 결과가 다르거나 Kramdown 이외의 변환기를 사용하면 검토가 필요하다고 실패한다.
- 일반 페이지의 SEO 설명 보정은 작성자가 입력한 평문과 원본 Markdown의 의미가 같은지 Liquid만으로는 판단하지 못한다. 기본 빌드 생성물에 대한 별도 파서 검사를 실행해야 하며, 사용자 지정 추가 빌드 옵션이나 렌더 중 변경하는 생성기는 검증 범위에 포함하지 않았다.
- 일반 SEO `name`에 대한 평문은 원본 사이트·소셜·페이지 이름이 바뀌면 함께 갱신해야 한다. 기본 Pages 빌드만으로는 작성한 평문이 원본과 맞는지 검증할 수 없으며, 기본 빌드의 생성물 원본 비교 검사를 별도로 실행해야 한다. 사이트 제목이 원천인 JSON-LD `headline`의 별도 문자 참조 경계는 아직 일반적으로 보정하지 않았다.
- 성과의 프로젝트·이미지 URL은 신뢰된 작성자가 입력한다. 허용 정책과 HTML 이스케이프는 전체 URL·호스트의 유효성이나 실제 대상의 존재를 보장하지 않는다. 허용 범위와 발행 전 검사 방법은 운영 문서를 참고한다.
- 실제 기기의 한국어 조합 입력과 스크린리더·모바일 키보드로 검색 및 메뉴를 확인한다.
- 현재 한국어 글의 MathJax 수식 음성 데이터는 기본적으로 영어다. 한국어 기본값 후보는 정상 상태에서 한국어 음성을 생성하고 저장된 영어 선택을 존중했지만, 한국어 사전만 404가 되면 수식은 보여도 음성이 생성되지 않고 지연 안내가 지속돼 적용하지 않았다. 같은 시험에서 기존 영어 기본값은 정상이었다. 별도 격리 Chrome에서는 키보드로 수식 메뉴의 영어를 선택하고 같은 출처의 설정을 덮지 않는 시험 페이지로 이동해 새로고침한 뒤 음성이 복구됐다. 이 조건부 복구 방법을 지연 안내에 추가했고, 실제 MathJax를 쓰는 격리 Chrome에서 한국어 사전만 차단하면 안내가 보이고 정상 영어 음성이 생성되면 안내가 숨겨지는 것을 확인했다. 실제 스크린리더 낭독과 모든 장애·브라우저 조합은 미검증이다. MathJax가 역할 설명에 사용하는 U+0091은 공식 소스에서 의도된 값으로 확인해 변경하지 않았다. [MathJax 접근성 안내](https://docs.mathjax.org/en/v4.0/basic/a11y-extensions.html).
- 큰 숫자를 입력한 물리·단위 계산기의 실제 스크린리더 읽기와 브라우저별 숫자 입력 접근성 상태를 확인한다.
- 모든 외부 서비스 장애·브라우저 조합·콘텐츠의 학술적 정확성을 전수 검증하지 않았다.
- 검색어가 GA의 사이트 검색 자동 측정에 전달될 가능성은 사용자가 선택한 기존 설정 유지 상태로 남는다. 기존 검수 기록을 참고한다.
- 사용자가 작업 중 커밋과 푸시를 요청해 검증을 마친 변경부터 순차 배포한다.
