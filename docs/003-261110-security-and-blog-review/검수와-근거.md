# 블로그 기능·보안 검수와 참고 근거

기준일: 2026-11-10. 이 문서는 로컬 작업과 검수 범위를 기록한다. 커밋·배포 여부는 Git 상태와 실제 Pages 배포에서 별도로 확인한다.

## 질문과 방법

19개 글을 가진 정적 연구 블로그에서 독자가 글을 찾고, 순서대로 읽고, 도구를 사용하고, 구독하는 데 필요한 기능을 확인했다. 저장소 코드와 Jekyll 생성물, 주요 브라우저 동작을 검토하고, 공개 블로그 사례 및 공식 문서를 비교했다. 사례 비교는 소수 사이트의 공개 화면 관찰이며 독자 이용률이나 기능 효과를 측정한 연구가 아니다.

## 외부 사례와 판단

- [Lilian Weng](https://lilianweng.github.io/)은 글 목록·검색·태그를, [Andrej Karpathy](https://karpathy.github.io/)는 날짜와 요약 중심 목록을, [colah](https://colah.github.io/)은 주제별 글 묶음을 제공한다. 이들은 가능한 탐색 패턴의 사례이며 특정 기능의 효과를 증명하지 않는다.
- 이 사이트에는 검색, 카테고리, 시리즈, 목차와 이전·다음 글이 이미 존재한다. 기존 기능의 연결과 상태를 바로잡는 것을 우선하고, 별도의 회원 기능이나 추천 알고리즘은 추가하지 않았다.
- [jekyll-feed 공식 문서](https://github.com/jekyll/jekyll-feed)는 Atom 피드와 자동 발견 메타데이터를 제공한다. 기존에 생성되던 피드에 발견 메타데이터와 구독 링크를 연결했다. 피드 리더 앱별 동작은 별도 확인이 필요하다.
- [W3C의 페이지 내 탐색 안내](https://www.w3.org/WAI/tutorials/page-structure/in-page-navigation/)는 제목 ID와 목차가 긴 페이지의 탐색 및 특정 구간 참조를 도울 수 있다고 설명한다. 해당 안내는 진행 중인 초안이며 사용자 실험의 대체 근거는 아니다.

## 코드와 의존성 검수

- npm 감사에서 기존 잠금 파일 기준 개발·테스트 의존성 `happy-dom`, `vite`, `source-map-js`의 권고가 확인되어 각각 21.0.4, 8.3.7, 1.2.2로 갱신했다. 변경 후 npm 감사 결과는 0건이다. 이는 감사 시점의 npm 잠금 파일에 대한 결과이지 전체 보안이나 다른 생태계에 대한 보증이 아니다. [Happy DOM 권고](https://github.com/advisories/GHSA-834v-8h66-3h79), [source-map-js 권고](https://github.com/advisories/GHSA-68fv-2mgg-jv7q), [Vite 권고](https://github.com/vitejs/vite/security/advisories/GHSA-rq7h-c2jc-7f22).
- GitHub Dependabot 상세 목록은 인증 문제로 확인하지 못했다. npm 감사의 기존 권고 수와 GitHub가 표시한 수가 같더라도 두 목록이 같거나 알림이 닫혔다고 단정할 수 없다.
- MathJax는 npm lock 밖에서 CDN으로 로드된다. 기존 2.x의 [권고](https://github.com/advisories/GHSA-v638-q856-grg8)는 벤더가 악용 가능성에 이의를 제기한다. 4.1.3 전환은 별도로 렌더링을 검증하며, CDN에 대한 의존과 후속 리소스 로드는 남는다. [MathJax 설정 문서](https://docs.mathjax.org/en/latest/web/configuration.html).
- 로컬의 미추적 `Gemfile.lock`과 GitHub가 관리하는 Pages 빌드의 gem 버전은 다를 수 있다. 로컬 Ruby 버전 대조 결과를 GitHub 알림이나 운영 환경의 실제 악용 가능성으로 취급하지 않았다. [GitHub Pages 의존성 목록](https://pages.github.com/versions.json).

## 기능 보강과 사실 확인

- 시리즈의 내부 정렬 키와 표시 순서를 분리하고, 도구 안내에서 해당 계산 탭과 공식으로 직접 이동하도록 했다. 개별 도구 안내 페이지도 검색 대상에 포함했다.
- 자동 계산기가 준비 중인 DSR 안내의 금융위원회 링크에는 2020년·2022년 자료임을 명시했다. 해당 링크가 현재 대출 기준을 확정하는 것은 아니다. [2020년 Q&A](https://www.fsc.go.kr/po020201/27351), [2022년 고시](https://www.fsc.go.kr/po040200/78432).
- 성과 상세의 임시 문구와 이미 메타데이터로 표시되는 중복 본문을 제거했다. 별도의 경력 사실을 새로 추가하지 않았다.

## Analytics와 남은 제한

- 실제 블로그 GA4 스트림에서 향상된 측정과 사이트 검색이 활성화되어 있고 URL 쿼리 키 가림은 비활성화되어 있음을 확인했다. 검색어가 `q`에 들어가는 구조이므로 개인정보를 포함한 검색어가 Analytics로 전송될 가능성이 있다. 실제 전송 패킷, 과거 수집 내용과 저장 범위는 확인하지 않았다. [Google 향상된 측정 문서](https://support.google.com/analytics/answer/9216061), [데이터 가림 문서](https://support.google.com/analytics/answer/13544947).
- 사용자는 분석과 현재 설정의 유지를 선택했다. 이에 따라 GA 속성 설정은 변경하지 않았다. 검색어별 통계의 유지와 개인정보 위험은 함께 남는다.
- 정적 검사에서 생성 HTML 전체와 내부 URL, 검색 인덱스, Atom 및 사이트맵을 확인했다. 외부 링크는 점검 도구가 확인한 범위로 한정되며, 모든 글의 학술적 주장, 모든 기기·스크린리더, 모든 외부 서비스 장애를 전수 검증한 것은 아니다.

## 최종 로컬 검증

- npm 레지스트리 감사: 0건. 임시 디렉터리에서 `npm ci` 재현 설치도 통과했다.
- `npm test`: TypeScript 검사, JavaScript 테스트 30건, Ruby 테스트 7건, Python 테스트 4건, Vite 빌드 통과.
- Jekyll 빌드와 생성물 통합 테스트 8건 통과. 최종 산출물 검사는 HTML 38개, 내부 URL 1,209개, fragment 41개, 검색 인덱스 항목 30개를 확인했다.
- 브라우저에서 홈의 Atom 링크, 가속도 검색 → 안내 페이지 → 계산기 선택, `20 ÷ 5 = 4 m/s²`를 확인했다. MathJax 전환은 별도 로컬 브라우저에서 분수·집합·조건부 확률·한글 수식, 로더 실패 시 원문 표시를 확인했다.
- 독립 외부 링크 검사에서 25개 중 24개를 확인했고 WHATWG 단일 페이지 1개는 시간 초과로 판단을 보류했다. 본 검사는 링크 대상의 사실 전체를 검증하지 않는다.
